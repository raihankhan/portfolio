# Milestones

This roadmap is divided into **8 milestones** mapped to the next 12 months. Each milestone has clear acceptance criteria and is tracked in the **Platform & FDE Roadmap** GitHub Project.

## v1.0 — Foundation: Senior Platform Engineer Brand

**Due:** Sept 2026
**Goal:** Reposition portfolio from DevOps to Senior Platform Engineer brand. Skills radar, architecture diagrams, enhanced project schema, SEO baseline.

## v1.1 — Operational Excellence: CI/CD, Testing, Quality Gates

**Due:** Oct 2026
**Goal:** Production-grade CI/CD: lint/typecheck, tests, Lighthouse CI, bundle analysis, security scans, preview deploys.

## v1.2 — Observability & SRE: SLOs, RUM, Error Tracking

**Due:** Nov 2026
**Goal:** Treat portfolio as a production product. OpenTelemetry RUM, error tracking, synthetic uptime, public status page, SLO definitions.

## v1.3 — Design System & DX: Tokens, Theming, Component Library

**Due:** Dec 2026
**Goal:** Semantic design tokens, accessibility audit, OKLCH palette, animation guidelines, component documentation.

## v2.0 — AI Portfolio: Showcase AI / Agentic Engineering

**Due:** Feb 2027
**Goal:** New AI/agent portfolio section. MCP server, RAG app, multi-step agent, eval harness, public dashboard.

## v2.1 — Knowledge Engine: Blog 2.0, Notes, OG Images

**Due:** Mar 2027
**Goal:** Content engine 2.0. MDX with schema validation, OG image generator at edge, RSS categories, content collections.

## v2.2 — Interactive Demos: Visualizer, Cost Calculator, K8s Lab

**Due:** May 2027
**Goal:** Interactive architecture visualizer, multi-cloud cost calculator, browser-based k8s lab.

## v3.0 — FDE Launch: Storytelling, Case Studies, Talk Bank

**Due:** Aug 2027
**Goal:** FDE-ready launch. Long-form case studies with problem/narrative/decision/outcome. Talk bank, system-design writeups, demo videos.

---

## How milestones map to FDE readiness

- **v1.0–v1.3** = "I'm a senior platform engineer" (the foundation)
- **v2.0** = "I'm an AI engineer" (the FDE pivot)
- **v2.1–v2.2** = "I can build production AI products" (breadth)
- **v3.0** = "I can talk about it credibly" (signal amplification)

Each milestone unlocks **new conversations** with new categories of hiring managers.
